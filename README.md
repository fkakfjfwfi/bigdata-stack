# 🐘 大数据技术栈

从一套 **16 天 Hadoop 实战课**提炼的纯静态教学站。零依赖、可离线、直接双击 `index.html` 就能看。

和「教材向」的笔记不同，这套内容的特点是把**课堂口述补成可复制的命令**，把**老师一句带过的坑写成对照表**，并且**每个知识点都标了视频时间戳**——有疑问可以回原片定位，不用重看四小时。

## 这套笔记怎么来的

1. **音轨转写** → 按主题重组，不逐字稿
2. **术语纠错** → ASR 把 NameNode 听成"内门node"、MapReduce 听成"迈普瑞丢斯"，全部按上下文还原
3. **口述补成命令** → "这里改一下""然后启动它"补成完整可复制的内容
4. **坑写成表** → 现象 → 原因 → 解法 → 判据关键字
5. **区分原课与补充** → 课程没讲但工程必需的（如 `-skipTrash`、机架拓扑配置），一律标「补充」

## 内容自检

改完内容跑一遍，六类检查一次过：

```bash
python check.py           # 全站
python check.py ch02      # 只查某一章
```

检查项：标签配对 / 章节编号连续 / 打卡数对齐 `app.js` 的 `TOTALS` / Markdown 语法残留 / 行内代码样式 / 未转义字符 / chip 类名白名单 / 每章是否有「内容基准」块。

退出码 0 表示通过，1 表示有问题。
